# Лабораторна робота №6 — матеріали перевірок

У цій папці зібрано скриншоти й короткі консольні результати виконаних перевірок. Опис реалізації, модель загроз і матеріали зауважень знаходяться в `docs/security-review.md`, `docs/threat-model.md` та `docs/findings/`.

## Скриншоти

- `01` — початковий запуск тестів (33/33).
- `02–04` — запуск API в Production і перевірки HTTP-відповідей.
- `05` — поведінка виходу до усунення CSRF-проблеми (F-01).
- `06–08` — додавання antiforgery та перевірка видачі CSRF-токена.
- `09–13` — перевірки виходу, недійсного токена, клієнтського helper і створення інциденту після виправлення.
- `14_final_regression_44_of_44.png` — підсумковий запуск 44 тестів без помилок.

## Консольні матеріали

- `15_csrf_regression_38_of_38.txt` — проміжна регресія після виправлення F-01.
- `16_search_rate_limit_before_after.txt` — порівняння результатів до та після виправлення F-02.
- `17_sql_injection_search_regression.txt` — результат ручної перевірки пошукового запиту і спеціальних символів.

Вміст файлів — докази конкретних перевірок; проміжні результати 33/33 та 38/38 не замінюють фінальну регресію 44/44.
