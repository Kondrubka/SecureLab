
# Access Control Matrix - Lab 04

## Baseline 2-A

Головна захищена операція: GET /api/incidents/{id}.

| Суб'єкт | Ресурс | Рішення | HTTP |
|---|---|---|---|
| Anonymous | Будь-який інцидент | Deny | 401 |
| Reporter (Alice) | Власний інцидент | Allow | 200 |
| Reporter (Alice) | Інцидент Bob | Deny | 403 |
| Analyst (Morgan) | Інцидент Alice або Bob | Allow для аналізу | 200 |
| Administrator | Чужий інцидент без окремого дозволу | Deny | 403 |
| Authenticated user | Неіснуючий інцидент | Not Found | 404 |

## HTTP denial policy

Для автентифікованого користувача без права доступу обрано 403 Forbidden.

401 Unauthorized використовується для анонімного запиту.

404 Not Found використовується для неіснуючого ресурсу.

## Authorization rule

Ідентифікатор користувача визначається з перевіреного ClaimsPrincipal.

Reporter може переглядати лише власні інциденти.

Analyst може переглядати інциденти інших користувачів для аналізу, але не отримує автоматичного права змінювати чи видаляти їх.

Роль Administrator не означає автоматичного доступу до всіх ресурсів.

## IDOR/BOLA finding

До виправлення Alice отримує HTTP 200 під час читання інциденту Bob.

Причина: сервер знаходить Incident лише за його identifier без перевірки ownership або дозволеної ролі.

Очікуване виправлення: централізована перевірка прав доступу перед поверненням IncidentDetailsResponse.

Залишковий ризик: інші маршрути читання та зміни ресурсів потребують окремого контролю доступу на наступних етапах.
