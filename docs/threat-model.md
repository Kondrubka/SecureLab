## 2. Архітектура та активи

Активи: облікові записи й сесії, записи інцидентів, коментарі, історія зміни статусів, дані авторизації, конфігураційні секрети та журнали аудиту.

Суб'єкти: анонімний відвідувач, автентифікований Reporter, привілейований Analyst, локальний розробник.

## 3. Межі довіри

Архітектура: браузерний клієнт передає HTTP-запити
до ASP.NET Core API, який звертається до PostgreSQL
через Entity Framework Core та Npgsql.

Додаткові межі: Git і залежності збірки,
змінні середовища та конфігурація,
журналювання подій застосунку.

| Межа | Загроза | Контроль | Перевірка |
|---|---|---|---|
| Browser -> API | CSRF | Antiforgery та CsrfEndpointFilter | REG-CSRF, PASS |
| Browser -> API | XSS | CSP та безпечні DOM-операції | CSP і DOM-тест |
| User -> API | IDOR | IncidentAccess та авторизація | A03/A03R |
| Client -> Search API | Надмірні запити | search-limit | REG_RATE_SEARCH_01/02 |
| API -> PostgreSQL | SQL injection | EF Core, параметризація | Окремий payload-тест не підтверджено |
| Git -> runtime | Витік секретів | Змінні середовища, ротація | SEC-SECRET-01/02 |
| Dependencies -> build | Вразливі пакети | NuGet audit | DEP-AUDIT-01, PASS |
| API -> logs | Відсутність аудиту | SecureLab.Audit | REG-AUDIT-02/03/04 |
| API -> client | Витік деталей помилок | ProblemDetails | REG-ERROR-500-01 |

У межах роботи: поточні відстежувані файли, конфігурація, API, браузерні сценарії, регресійні тести, залежності, журнали та основні HTTP-заголовки.
